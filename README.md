# 予花知爱

一个面向鲜花半定制与配送的小程序项目。用户可以选择送花场景、主花、色系、花束版型和包装材质，填写配送信息与寄语后下单；店家可以查看订单并更新制作、配送状态；平台可以管理订单、审核社区晒图并查看运营信息。

项目包含三类界面：

- 用户端：花束定制、下单、订单确认、社区浏览与互动。
- 店家端：接单、制作中、已配送、已完成等订单处理流程。
- 平台端：用户与订单管理、社区内容审核、交易与结算查看。

后端基于 Node.js Express，按微信云托管 Express 模板整理，支持账号权限、订单接口、图片资源、微信支付对接预留、MySQL 存储和对象存储对接。小程序端通过微信云托管域名访问后端接口。

当前后端入口位于 `server/`，小程序入口位于 `miniprogram/`。
